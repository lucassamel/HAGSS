# HAGSS

High Availability Global Scheduling System

ASP.NET Core Web API project.

## Requirements

- [.NET SDK](https://dotnet.microsoft.com/download) (see `HAGSS/HAGSS.csproj` for target framework)

## Run locally

```bash
dotnet run --project HAGSS
```

API documentation (OpenAPI) is available in Development at `/openapi/v1.json`.
